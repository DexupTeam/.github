# Dexup

**Ta collection de cartes Pokémon, dans ta poche.**

[Ouvrir l'app](https://dexup.netlify.app) · [Code de l'app](https://github.com/DexupTeam/DexupApp)

</div>

---

Dexup est une application web (PWA) gratuite pour suivre sa collection de cartes Pokémon TCG : elle s'installe sur l'écran d'accueil du téléphone comme une app, et marche aussi sur ordinateur.

## Ce que fait Dexup

- **Toutes les extensions**, anglaises, japonaises et chinoises, avec les noms en français
- **Scanner** : pointe la caméra sur une carte, Dexup la reconnaît (anglais, français, japonais, chinois), directement dans le navigateur
- **Valeur de la collection** d'après les prix Cardmarket, avec l'évolution des prix dans le temps
- **Classeur** : listes, favoris, cartes gradées, photos de tes propres cartes
- **Produits scellés** : boosters, displays, ETB, avec leurs prix
- **Communauté** : profils publics, vitrine de tes plus belles cartes, abonnements
- Actualités du TCG et agenda des salons

## Données et remerciements

Dexup s'appuie sur des données ouvertes : [Pokémon TCG API](https://pokemontcg.io), [TCGdex](https://tcgdex.dev) (prix Cardmarket), [CardCorpus](https://github.com/cardcorpus) (cartes japonaises et chinoises, modèles du scanner, CC BY 4.0 / Apache 2.0) et le relevé public de [Cardmarket](https://www.cardmarket.com).
